# Support

Datanotes is maintained by one person in their spare time. There is no paid support and no
guaranteed response time. These places help you find an answer.

## Read the docs

The documentation at [datanotes.dev](https://datanotes.dev) covers these topics:

- Installing and starting the engine
- Defining tables, views and bases
- Connecting agents through the Model Context Protocol (MCP) server
- Every operation, error and setting

Each error the engine returns has a `hint` and a `docs` link. Follow them first.

## Ask a question

Ask how to do something in
[GitHub Discussions](https://github.com/davidefornelli/datanotes/discussions). Search it first: the
answer may already be there.

## Report a bug or request a feature

Open an [issue](https://github.com/davidefornelli/datanotes/issues/new/choose) and pick its form.
Include a minimal reproduction made with invented data. Never paste your real notes, your
`settings.json` or a token.

## Report a vulnerability

Don't open a public issue. Follow [SECURITY.md](SECURITY.md) instead.

## Report a conduct problem

Follow the enforcement section of the [Code of Conduct](CODE_OF_CONDUCT.md).
