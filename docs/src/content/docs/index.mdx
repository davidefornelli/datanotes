## Why use Datanotes

<p class="dn-lead">Your notes stay plain Markdown files. The engine adds what a database gives you.</p>

<div class="not-content dn-cards dn-features">

- [Tables from your notes](/guides/database-objects/tables/)

  Each note with a `table` property is a row. One file, `metastore.yaml`, defines the columns.

- [Every write checked](/guides/data-quality/validation/)

  The engine checks types, links, unique values and CHECK rules. It refuses a bad write and changes nothing.

- [All or nothing, with many clients](/develop/concurrency/)

  Agents, programs and your phone write at the same time. Each write is checked on the latest data and applies whole or not at all.

- [Joins, views and bases](/guides/read-and-write/joins-and-aggregates/)

  Filter, join and aggregate rows. Save a query as a view, and share columns through bases.

- [History, time travel and undo](/guides/history/journal-and-undo/)

  The journal records every write through the engine and who made it. Undo a write, or, with history on, read a table as it was last week.

- [Made for agents](/start/connect-agents/)

  Claude, Cursor and Codex call every operation through the Model Context Protocol (MCP). Each refusal says how to fix the call.

- [HTTP API and client](/develop/http-api/)

  Programs call the same operations over HTTP, or from JavaScript with `datanotes/client`.

- [Search by text, meaning and links](/guides/search/text/)

  Search the text of every note, find notes by meaning, and walk the links between them.

- [Git sync and store backup](/administration/git-sync/)

  The engine commits and pushes your vault with git. A private repository backs up undo and history too.

- [Edit notes by hand](/guides/data-quality/hand-edits/)

  Use Obsidian, VS Code or git. The engine checks each edit and reports what it breaks.

</div>

## What you can build

<p class="dn-lead">The guides build one example you can follow: a diary of classic films in the public domain.</p>

<div class="not-content dn-uses">

- [A second brain for your agent](/guides/agents/how-agents-use-datanotes/)

  Tell your agent you watched Metropolis with Anna. It logs the viewing and finds it when you ask next month.

- [Databases in your notes](/guides/database-objects/relations/)

  Keep films, actors, genres and viewings as linked tables. Every row stays a note you can open and edit.

- [Apps over your vault](/develop/build-an-app/)

  Build film night, a TypeScript app that lists the films to watch and logs each viewing.

- [Several agents, one memory](/guides/security/tokens/)

  Give each agent and script its own token. The journal shows which one wrote what.

</div>

## Run it on your notes

<p class="dn-lead">You need Node.js 22 or newer and a folder for your database: an empty one, or a folder of notes.</p>

<div class="dn-start">

<div class="dn-steps">

<Steps>

1. Start the engine on your folder:

   ```bash
   npx -y datanotes serve --database your_database_folder
   ```

2. Connect your agent. This command adds Datanotes to Claude Code, and [Connect your agents](/start/connect-agents/) covers Cursor, Codex and others:

   ```bash
   claude mcp add datanotes -- \
     npx -y datanotes mcp --database your_database_folder
   ```

3. Ask in your own words:

   ```text wrap
   Make a table of the classic films I watch, then add Nosferatu (1922).
   ```

</Steps>

</div>
